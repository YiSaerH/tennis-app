## 接线（原型）

```
XIAO nRF52840          WS2812 灯板        按键(轻触开关)
D2  ──────────────────  DIN
3V3 ──────────────────  5V/VCC
GND ──────────────────  GND ────────────── 按键一脚
D3  ────────────────────────────────────── 按键另一脚

锂电池(401230) ── XIAO 背面 BAT+ / BAT- 焊盘（注意极性！）
USB-C ── 直接插 XIAO（充电 + 烧写二合一）
```

电池电压走板载分压 + `VBAT_ENABLE(P0.14)` 开关，固件已在 `setup()` 里把它拉低，**不要**把电池直接接到任何 IO。

## 烧写步骤（Arduino IDE）

1. 装板级包：文件 → 首选项 → 附加开发板管理器网址，添加
   `https://raw.githubusercontent.com/seeed-studio/Adafruit_nRF52_Arduino/master/package_seeed_nrf52_index.json`
   （国内打不开就挂代理，端口 7897 那个）。
2. 开发板管理器搜 `Seeed nRF52` → 安装 **Seeed nRF52 Boards**。
3. 库管理器装 **Adafruit NeoPixel**（bluefruit 已随板级包自带）。
4. 开发板选 **Seeed XIAO nRF52840**，端口选对应的 COM 口。
5. 多个饰品要区分：改 `Bluefruit.setName("Tennis Charm 01")` 里的编号。
6. 上传（XIAO 进 bootloader 的方法：插上 USB 后快速双击复位键，板上 LED 变常亮即进入）。

## 验证清单（对着小程序「球友 → 我的饰品」逐项过）

- [ ] 上电：呼吸灯（网球黄绿），USB 插上充电
- [ ] 小程序点「搜索并绑定饰品」→ 能看到 `Tennis Charm 01` 并连上
- [ ] 连上后状态卡显示电量百分比（和万用表实测电压对照，偏差大就按下面校准）
- [ ] 切 7 种模式，灯实时变；拖亮度滑杆灯变亮变暗；点色块换颜色
- [ ] 「闪一下」→ 3 次快闪后回到原模式
- [ ] 短按按键循环模式；长按 800ms 熄灯
- [ ] 手机蓝牙关掉 → 小程序弹「饰品已断开」防丢提醒
- [ ] 隔 ~1 分钟后电量服务有更新

## 电量校准

固件按官方 `adc_vbat` 示例读：`AR_INTERNAL_3_0` 基准 + 12 位分辨率 + 1/2 分压补偿。
百分比按 3.5V→0%、4.2V→100% 线性估算。如果和实测偏差大，改 `pollBattery()` 里的
`3500.0F` / `700.0F` 两个常数即可。
