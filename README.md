# 网球记 — 我的网球日志

一个手机/电脑都能用的网球记录 PWA（渐进式网页应用）。记录球拍参数（重量、线磅数、挥重、穿线日期）、穿线提醒、每次打球的对手和时长，自动统计。安卓和苹果都能"安装"到桌面当 app 用，离线可用，不用上架、不用审核。

仓库里还有一个功能对等的**微信小程序版**（`miniprogram/` 目录），可发布到微信里用，见下文[「微信小程序版」](#微信小程序版miniprogram)。

## 功能

- **打球记录**：日期、对手、时长、用了哪把拍子、备注；可按月份/对手筛选，可搜索
- **月历视图**：打球记录页顶部显示当月日历，打了球的日子高亮标出；点某天只看那天的记录，‹ › 可翻月
- **我的拍子**：名称、重量(g)、线磅数(lbs，支持横/竖不同磅数，如 46/48)、挥重、线型、穿线日期
- **穿线提醒**：某把拍子已穿超 45 天 **或** 累计打球超 15 小时 → 自动提醒换线；换好新线点"记录换线"重置计时
- **统计**：总次数、累计小时、本月打球、常一起打球的人排行
- **数据本地存储 + 导出/导入**：数据存在设备本地，可导出 JSON 备份，换设备时导入

## 本地用

双击 `index.html` 即可在浏览器打开使用。（注意：直接打开文件时，离线缓存和"安装"功能不生效——需要通过 http/https 访问，见下面。）

## 本地起服务器测试（让"安装"功能生效）

在当前目录运行（任选一种）：

```bash
python -m http.server 8080
# 或
npx serve
```

然后浏览器打开 http://localhost:8080/ —— 此时 service worker 会注册，可以测试"安装"。

## 安装到手机当 app 用

发布到网上后（见下），用手机浏览器打开网址：

### 安卓（Chrome）
1. 用 Chrome 打开网址
2. 点右上角 ⋮ 菜单 → **安装应用** / **添加到主屏幕**
3. 桌面出现"网球记"图标，点开就是全屏 app，离线也能用

### 苹果（Safari）
1. 用 Safari 打开网址
2. 点底部 **分享** → **添加到主屏幕**
3. 桌面出现"网球记"图标

> 苹果版"添加到主屏幕"和网页略有不同：有独立图标、全屏、像 app。这是当前给苹果用户的方案（暂不做原生 iOS app）。

## 发布到网上（让手机能装）

挑一个免费的静态托管服务，把整个文件夹传上去即可得到一个 https 网址：

### 方式一：Netlify（最简单，拖拽）
1. 打开 https://app.netlify.com/drop （需登录，可用 GitHub/邮箱注册，免费）
2. 把整个 `网球记` 文件夹拖进去
3. 得到一个网址，例如 `https://tennis-log-xxxx.netlify.app`
4. 把这个网址发给球友，安卓/苹果都能装

### 方式二：Vercel（命令行）
```bash
npm i -g vercel   # 或 npx vercel
vercel             # 在当前目录执行，按提示操作
```

### 方式三：GitHub Pages
1. 把文件夹 push 到一个 GitHub 仓库
2. 仓库 Settings → Pages → Source 选 `main` 分支
3. 得到 `https://用户名.github.io/仓库名/`

> 发布后，在手机 Chrome 用 Lighthouse 或直接看地址栏是否出现"安装"提示，可确认 PWA 配置正确。

## 微信小程序版（miniprogram/）

功能与网页版完全对等：打球记录（月历 + 筛选搜索）、球拍参数（支持横/竖磅数如 46/48）、穿线提醒（45 天或 15 小时）、统计、JSON 备份。全部数据存在手机本地（微信的 storage），**不需要服务器、不需要域名、不需要 ICP 备案**。

### 本地跑起来

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 打开开发者工具 → 导入项目 → 目录选本仓库的 `miniprogram/`，AppID 先用"测试号"即可
3. 左侧模拟器里即可完整体验；点工具栏"预览"生成二维码，微信扫码可在真机上试

### 发布流程

1. 到 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册一个小程序账号（**个人主体即可，免费**）
2. 拿到 AppID 后，把 `miniprogram/project.config.json` 里的 `"appid": "touristappid"` 换成自己的 AppID
3. 开发者工具里点**上传**，填版本号（如 1.0.0）和备注
4. 回到 mp.weixin.qq.com → 管理 → 版本管理 → 对刚上传的开发版本**提交审核**（一般几小时到 1–2 天）
5. 审核通过后点**发布**，微信里搜索小程序名称即可用，也能转发给球友

> 服务类目选"工具"类即可，功能如实描述（记录打球、管理球拍参数的离线工具）。个人主体不能开通支付等能力，本应用用不到。

### 网页版 ↔ 小程序数据互导

两边数据格式完全一致（同一套 `tennis_log_v1` 结构），按 id 合并、不会重复，同一条记录以导入的备份为准：

- **网页 → 小程序**：网页版点 ⬇️ 导出得到 `.json` 文件，用任意文本编辑器打开全选复制；小程序统计页点 ⬆️ 导入备份 → 粘贴到弹窗 → 确定
- **小程序 → 网页**：小程序统计页点 ⬇️ 导出备份（JSON 已复制到剪贴板），粘贴到文本编辑器存成 `.json` 文件；网页版点 ⬆️ 选择该文件导入

### 开发相关

- 核心逻辑全在 `miniprogram/utils/store.js`，与网页版 `index.html` 里的逻辑同构——改功能时两边同步改
- 跑自测：`node test-store.js`（覆盖日期解析、穿线提醒边界、月历、统计、导入导出，50 个断言）
- 改 tabBar 图标：改 `gen-tabbar-icons.js` 里的形状/颜色后运行 `node gen-tabbar-icons.js`

## 数据备份

数据存在**每台设备的浏览器本地**。换设备、清浏览器缓存前，用右上角 ⬇️ 按钮导出 JSON 备份；新设备用 ⬆️ 导入。建议定期导出存一份。

> 小程序的数据存在微信里，与网页版各自独立；互导方法见上文「网页版 ↔ 小程序数据互导」。

## 升级到 Google Play（可选）

如果想进安卓应用商店，可用 **Capacitor** 把这套网页包成真正的 APK：

- 需要：Android 构建工具（Android Studio + SDK）或用 Expo EAS 云构建
- Google Play 开发者一次性注册费 $25
- 纯 WebView 套壳要加够原生功能（本地通知提醒换线等）才容易过审

当前 PWA 方案已经能覆盖"安卓安装 app + 苹果用网页"的需求，商店发布可日后再做。
