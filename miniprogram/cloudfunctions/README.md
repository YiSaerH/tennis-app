# 云函数：球友地图

三个函数配合 `presence` 集合实现"谁在球场"的密度图：

| 函数 | 作用 |
| --- | --- |
| `report` | 小程序上报 / 更新 / 删除自己的位置网格（心跳 10 分钟、打卡 2 小时、下线立即删除） |
| `density` | 查询附近 ±0.15° 的网格人数（只返回网格中心 + 人数） |
| `cleanup` | 定时器每 30 分钟清理过期记录 |

## 部署步骤（微信开发者工具）

1. 开通云开发：工具栏「云开发」→ 开通并创建环境（免费额度足够个人使用）。
2. 在云开发控制台创建集合 **`presence`**（数据库 → 集合 → 新建）。
   - 权限选「仅创建者可读写」即可（云函数用管理权限访问，不受此限制）。
3. 右键 `cloudfunctions/report` →「上传并部署：云端安装依赖」，`density`、`cleanup` 同样操作。
4. `cleanup` 上传后，右键 →「上传触发器」启用 30 分钟定时清理。
5. 打开 `miniprogram/app.js`，确认 `presence.initCloud()` 已在（本仓库默认走环境自动初始化；如控制台提示需要指定环境 ID，把 `wx.cloud.init({ env: '你的环境ID' })` 写进 `utils/presence.js` 的 `initCloud` 里）。
6. **改盐**：`report/index.js` 里的 `SALT` 换成自己的随机字符串。

## 隐私声明（重要）

小程序管理后台（mp.weixin.qq.com）→「开发」→「开发管理」→「接口设置」里，
为 **`getFuzzyLocation`（模糊位置）** 填写用途说明（示例）：

> 用于在球友地图上显示你和附近球友的密度，只上传约 1 公里的网格点，不涉及精确位置。

不申请精确定位 `getLocation`，全链路只用模糊位置 + 网格化 + 自动过期。

## 隐私设计

- 文档 `_id` = openid 的 HMAC-SHA256 摘要前 16 位 —— 云端不存任何可反查的身份。
- 只存 `"纬度,经度"` 各保留 2 位小数的网格（约 1.1 km × 1.1 km）。
- 心跳 10 分钟过期、打卡 2 小时过期、关闭共享立即删除，另有定时兜底清理。
